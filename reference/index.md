# Package index

## Inspection Addins

Addins applying an inspection function to the current editor selection
and executing it in the console.

- [`xStrX()`](xStrX.md) : xStrX Run strX() on selected text.
- [`xSummary()`](xSummary.md) : xSummary Run summary() on selected text.
- [`xAbstract()`](xAbstract.md) : xAbstract Run abstract() on selected
  text.
- [`xHead()`](xHead.md) : xHead Run head() on selected text.
- [`xDesc()`](xDesc.md) : xUnclass Run desc() on selected text.
- [`xUnclass()`](xUnclass.md) : xUnclass Run head() on selected text.
- [`xExample()`](xExample.md) : xExample Run example() on selected text.
- [`xPlot()`](xPlot.md) : xExample Run example() on selected text.

## Interactive Dialogs

Tcl/Tk dialogs returning an R expression for the made selection.

- [`selectVarDlg()`](selectVarDlg.md) : Interactive variable selection
  dialog
- [`.orderSelectionDlg()`](dot-orderSelectionDlg.md) : Select ordering
  mode

## Editor Utilities

Writing back into the document and converting the selected text.

- [`flushToSource()`](flushToSource.md) : Insert selected object as
  reproducible R code
- [`toggleUnicodeAddin()`](unicodeAddins.md) : Unicode RStudio Addins
- [`escapeUnicode()`](escapeUnicode.md) : Escape Unicode Characters
- [`unescapeUnicode()`](unescapeUnicode.md) : Unescape Unicode
  Characters

## Data Helpers

Functions used by the addins and useful on their own.

- [`some()`](some.md) : Random subset of an object
- [`.str1()`](dot-str1.md) : xExample Run strX() on selected text
  display first element only.
